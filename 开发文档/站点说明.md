# 小游戏合集 · 站点说明

## 一句话

一个静态站点，首页 24 个卡片（23 个游戏 + 1 个赞助作者），卡片和分类由 `assets/data/games.js` 渲染，带搜索。没有框架、没有构建、没有后端，推上 GitHub Pages 就能用。

线上地址：<https://zhanjhe.github.io/online-games/>

## 页面怎么写

首页和赞助作者页用 `assets/css/site.css`。游戏页也引它，拿到这些东西：

- 背景、字号、颜色变量
- `.page--game` 外壳：顶部返回栏 + 居中主区 + 底部说明
- `.hud` 分数栏、`.btn` 按钮、`.pad` 触屏方向键、`.overlay` 结束遮罩

旧 11 个游戏页把外壳、棋盘样式、脚本都写在自己的 `index.html` 里。新 12 个游戏改成「外壳 + 棋盘样式 + 玩法脚本」三块：

```html
<script src="../assets/js/sfx.js"></script>
<script src="../assets/js/game-kit.js"></script>
<script>
var g = GameKit.mount({
  id: "tictactoe", title: "井字棋", tag: "TIC TAC TOE", accent: "#6D5D7B",
  tip: "点格子落子",
  hud: [{ id: "streak", label: "连胜" }],
  actions: [{ id: "restart", label: "重开" }],
  stage: '<div class="ttt-board" id="board"></div>'
});
</script>
```

`mount` 生成 `.page--game`、标题栏、HUD、`.stage`、遮罩和说明，返回 `$ / show / hide / onOverlay / sound / best / saveBest / get / set`。另外 `GameKit.canvas` 处理 DPR，`GameKit.loop` 截断 `dt`，`GameKit.pad` 生成触屏方向键，`GameKit.shuffle` 洗牌。

## 音效

所有游戏共用 `assets/js/sfx.js`，用 Web Audio 现场合成，不加载音频文件，仓库里没有 mp3 / wav。页面里加一行 `<script src="../assets/js/sfx.js"></script>`，在事件处调用 `SFX.play("名字")`。

- 音色表：`tick` 轻点、`place` 落子、`flip` 翻牌、`select` 选择、`match` 达成、`miss` 失败、`eat` 吃到、`brick` 打砖、`boom` 踩雷、`lose` 结束、`win` 通关、`spin` 起转
- 音量：单音峰值 0.10–0.16，主输出 0.55，再过 2600Hz 低通；同一个音效 50ms 内只响一次
- 开关：有 `.game-top` 的页面自动在标题栏右侧插入按钮，`game-tag` 让位；塔罗没有标题栏，按钮固定在右下角
- 状态：`localStorage` 的 `sfx.muted`（`1` 静音），全站共用；按钮带 `aria-pressed` 和 `aria-label`
- 浏览器要求先有用户操作才能出声，进页面第一次点击或按键之前的音效会被跳过；塔罗分享链接直接进结果页时不响

## 首页

标题「RK的小游戏合集」下面一行「23 个小游戏，点开即玩」（数字按数据里的游戏数算），再往下是搜索框、分类 chips 和 24 张卡：

- 数据来自 `assets/data/games.js`，每张卡有 `id / name / tag / desc / cat / accent / icon / href / keywords`
- 桌面 4 列 × 6 行，860px 以下 2 列 × 12 行
- 分类：街机 6、益智 7、棋牌 3、反应记忆 5、趣味测试 2
- 搜索匹配名字、说明、英文标签、关键词和分类名；和分类同时生效
- 有搜索词或选中分类时隐藏赞助卡，显示「找到 N 个」；搜不到显示空态
- 按 Esc 清空搜索和分类，回车打开第一张卡
- 卡片顺序就是 `games.js` 里的顺序，赞助作者固定最后

分类 id 和名字在 `games.js` 的 `CATS` 里改。

## 老链接兼容

以前塔罗测评在根路径，分享出去的链接是 `https://.../online-games/?r=moon`。搬到 `tarot/` 以后，首页 `<head>` 里有一小段脚本：URL 带 `r` 参数就 `location.replace("tarot/index.html?r=...")`，旧链接继续有效。

## 跨页面的约定

- 顶层扁平目录，返回首页统一写 `../index.html`
- 跳游戏写带文件名的路径（`tetris/index.html`），这样本地双击也能用
- 游戏内的分数存 `localStorage`，键名带游戏前缀：`tetris.best`、`2048.best`、`memory.best`、`snake.best`、`breakout.best`、`slide.best`、`mole.best`；新游戏由 `game-kit` 统一成 `<id>.best`
- 其余状态：`sokoban.level` 关卡进度、`sfx.muted` 静音开关
- 读写 `localStorage` 全部包 try/catch，隐私模式不报错、只是不记分

## 验证

```powershell
node tools/check-pages.js          # 本地全部页面：断言 + 交互冒烟 + 截图
node tools/live-check.js           # 同上，跑线上地址
node tools/check-data.js           # 塔罗题库均衡性
node tools/shot.js                 # 塔罗流程截图
node tools/og.js                   # 重新生成 assets/og.png
```

`check-pages.js` 先校验数据：id 唯一、`href` 的页面存在、分类合法、图标和主题色齐全、每个游戏在 `smoke.js` 里有断言。然后检查：

- 首页 24 张卡、赞助卡最后、数量文案 23
- 搜「棋」得 3 张且赞助卡隐藏，搜「zzz」出空态，街机分类 6 张，清除筛选恢复 24 张
- 每个游戏页有音效模块、静音开关，`AudioContext` 可用
- 每个游戏跑一遍自己的冒烟断言
- 根路径 `?r=moon` 转发到塔罗并显示月亮

`og.js` 生成分享图时会隐藏搜索区、只留前 12 张卡，再按 630 高度缩放。

在这里全部通过再推，推完用 `live-check.js` 跑一遍线上。三个脚本里的 Chrome 路径都是写死的，换机器要改 `CHROME` 常量。

## 部署

仓库 `ZhanJHE/online-games`，Pages 走 `main` 分支根目录，`git push` 后自动重建，约一分钟生效。

新增游戏时记得：建目录 → 引 `assets/js/sfx.js` 和 `game-kit.js` 写页面 → 在 `assets/data/games.js` 加一条卡片数据 → 在 `tools/smoke.js` 加一条断言 → 跑 `node tools/check-pages.js`。
