# 小游戏合集 · 站点说明

## 一句话

一个静态站点，首页 8 个卡片（7 个游戏 + 1 个占位），每个游戏是一个独立页面。没有框架、没有构建、没有后端，推上 GitHub Pages 就能用。

线上地址：<https://zhanjhe.github.io/online-games/>

## 目录

```
index.html                 首页：8 个卡片，含老链接 ?r= 的转发
about/index.html           关于（暂时停用，只显示停用提示）
tarot/index.html           恋爱塔罗测评（24 题 → 8 张牌）
tetris/index.html          俄罗斯方块
wheel/index.html           恋爱转盘
2048/index.html            2048
memory/index.html          记忆翻牌

minesweeper/index.html     扫雷

assets/css/site.css        站点公共样式：变量、首页卡片、游戏页外壳、关于页正文
assets/og.png              首页分享缩略图（1200×630）

tarot/assets/...           塔罗页自己的样式、脚本、图（自包含，不跟站点共用）
tools/check-pages.js       全站自检：9 个页面 + 断言 + 截图

开发文档/预览/             截图产物（站点/ 是全站，live/ 是线上）
```

## 页面怎么写

首页和关于用 `assets/css/site.css`。游戏页也引它，拿到这些东西：

- 背景、字号、颜色变量
- `.page--game` 外壳：顶部返回栏 + 居中主区 + 底部说明
- `.hud` 分数栏、`.btn` 按钮、`.pad` 触屏方向键、`.overlay` 结束遮罩

每个游戏页只在自己 `<style>` 里写棋盘相关的东西，`<script>` 全部手写，不引任何库。

## 首页

标题「小游戏合集」下面一行说明，再往下是 8 个卡片的网格：

- 桌面 4 列 × 2 行
- 720px 以下 2 列 × 4 行
- 卡片顺序固定，第 8 张（右下角）现在是「更多在路上」占位卡；关于入口已撤下

卡片结构：`<a class="card">` 里放图标（内联 SVG）、名字、说明、右上角英文标签。改卡片顺序就改 `index.html` 里 `<a>` 的顺序。

## 老链接兼容

以前塔罗测评在根路径，分享出去的链接是 `https://.../online-games/?r=moon`。搬到 `tarot/` 以后，首页 `<head>` 里有一小段脚本：URL 带 `r` 参数就 `location.replace("tarot/index.html?r=...")`，旧链接继续有效。

## 跨页面的约定

- 顶层扁平目录，返回首页统一写 `../index.html`
- 跳游戏写带文件名的路径（`tetris/index.html`），这样本地双击也能用
- 游戏内的分数存 `localStorage`，键名带游戏前缀：`tetris.best`、`2048.best`、`memory.best`、`snake.best`
- 读写 `localStorage` 全部包 try/catch，隐私模式不报错、只是不记分

## 验证

```powershell
node tools/check-pages.js          # 本地全部页面：断言 + 交互冒烟 + 截图
node tools/live-check.js           # 同上，跑线上地址
node tools/check-data.js           # 塔罗题库均衡性
node tools/shot.js                 # 塔罗流程截图
node tools/og.js                   # 重新生成 assets/og.png
```

`check-pages.js` 会检查：首页卡片数是否为 8（7 个链接 + 1 个占位卡）、关于入口是否已撤下、塔罗页赞赏码是否已撤掉、每个游戏的画布/格子是否渲染、转盘能否转出结果、2048 能否生成新块、翻牌能否翻面、扫雷第一次点击是否安全，以及根路径 `?r=moon` 是否转发到塔罗并显示月亮。

在这里全部通过再推，推完用 `live-check.js` 跑一遍线上。三个脚本里的 Chrome 路径都是写死的，换机器要改 `CHROME` 常量。

## 部署

仓库 `ZhanJHE/online-games`，Pages 走 `main` 分支根目录，`git push` 后自动重建，约一分钟生效。

新增游戏时记得：建目录 → 写 `index.html` → 在首页加卡片 → 在 `tools/check-pages.js` 的 `CASES` 里加一项 → 跑一遍。
