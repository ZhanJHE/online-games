- **作品名称**：小游戏合集（仓库名 online-games）
- **作品链接**：<https://zhanjhe.github.io/online-games/>
- **姓名 / 学号**：（提交时填写）
- **完成方式**：全程用自然语言跟 AI 对话完成，没有手写代码，也没有安装开发环境

## 一、我想做什么

起因是我看到一个别人的网页测评站，觉得“点开就能玩、还能分享给朋友”这种形式很有意思。我想自己做一个类似的东西，但不想做成只有一个测评的页面，而是做成一个**能一直往里加东西的小合集**：首页是入口，点进去是各自独立的小游戏。

主题定在“女生之间的恋爱小游戏”。这类内容不需要客观准确，重点是氛围和分享欲。所以做了恋爱塔罗、恋爱转盘，另外配了几个经典小游戏（俄罗斯方块、2048、贪吃蛇等）撑起合集的分量。

目标只有一个：**手机上点开就能玩，不用注册、不用下载、不用等加载。**

## 二、三个主要页面

### 1. 首页：小游戏合集

八个长方形卡片，4 上 4 下，桌面 4 列、手机 2 列。每张卡片一个手写的线条图标、名字和一句说明，鼠标移上去边框变金色、轻微上浮，进入时按顺序错开淡入。

右下角是“关于”，其余 7 张是游戏。每个游戏有自己的主题色（俄罗斯方块砖红、转盘焦糖、塔罗紫、2048 金、翻牌灰紫、贪吃蛇苔绿、扫雷灰蓝），图标和进入后的按钮、分数数字是同一个颜色，进页面之后有连贯感。

### 2. 恋爱塔罗测评（7 个游戏里最完整的一个）

24 道情景题，每题 3 个选项，选完直接下一题，可以回退改答案。最后落到 8 张牌面之一：

> 月亮（夜里想太多）、太阳（喜欢就直说）、星星（远远看着也算参与）、女祭司（不说但都知道）、皇后（我来照顾你）、恋人（只想和你一起）、隐者（需要自己的时间）、魔术师（我喜欢的人我得追）

结果页有牌面插画、一段长文案、三个标签、八维柱状图、最佳配对和最佳友伴。并列最高时随机取一张当主牌，其余显示成“你身上还带点 XX 的影子”。

**分享链接会带上结果**：分享出去的地址形如 `?r=moon`，朋友点开直接看到你那张牌，按钮变成“我也要抽一张”。

### 3. 七个独立小游戏

每个游戏是一个单独的 HTML 文件，样式和脚本都内联，互不影响：

| 游戏 | 玩法 |
| --- | --- |
| 俄罗斯方块 | 10×20，键盘/触屏都能操作，消行加速，最高分存本地 |
| 恋爱转盘 | 8 个扇区，“主动发消息 / 等他开口 / 删掉他 / 刷朋友圈…” |
| 恋爱塔罗 | 见上 |
| 2048 | 方向键或滑动，新块有入场动画、合并有放大动画 |
| 记忆翻牌 | 4×4 八对符号，计步数和用时 |
| 贪吃蛇 | 20×20，吃到食物加速，不能 180 度掉头 |
| 扫雷 | 9×9 十颗雷，第一次点击必定安全，长按插旗 |

## 三、用了什么 AI 工具

用的是 **DeepSeek Harness 里的编码助手**（对话式 AI 编程工具），全程在对话框里用中文提需求。

它能做的事情里，对我帮助最大的是三件：

1. **直接读写项目文件**：我不用复制粘贴代码，只说“把计分牌挪到上面”，它就改文件。
2. **能自己截图验证**：它用无头浏览器打开页面、点按钮、截图，再告诉我哪一步失败了。我看截图提意见，它改。
3. **能操作 GitHub**：推送代码、打开 Pages、配置域名和缩略图，都是它做的。

## 五、项目里有一个我认为值得说明的取舍

第一版做完之后，我把“赞赏码”和“关于”两块临时撤了下来，并把仓库历史压缩成了一个提交。原因是当时用的赞赏码和页面里有些内容让我不太想公开。

后来换成新的赞赏码，只放在“关于”页最底下，不再放在结果页，避免每测一次都被摆到眼前。这件事让我意识到：**做给别人看的页面，“放什么、放哪里”也是设计的一部分，不完全是审美问题。**

## 六、没做好的地方（反思）

1. **旧的提交没有真正消失**。我把历史重置成了一次提交并强推覆盖，但 GitHub 上旧提交仍然可以通过链接访问（我测过，返回 200）。要彻底清掉得删库重建或者请官方回收，我暂时没做，因为删库有风险。
2. **没有排行榜**。分数只存在自己浏览器里，换设备就没了。要做服务器排行榜就必须有后端，这超出了“纯静态”的范围。
3. **2048 的动画是简化版**。现在只有新块弹出和合并放大，没有从旧位置滑到新位置的位移动画。
4. **没有声音**。方块消除、转盘转动都没有音效，加的话要考虑不是所有人都喜欢自动发声。
5. **关于页被撤下来过一次**。这属于内容决策反复，说明我一开始没想清楚这个站要给别人看什么。
